How it works

Native. Frugal. Self-contained.

Written in Swift and SwiftUI, shipped as a 2.4 MB menu bar agent with no runtime dependencies beyond macOS itself.

Apple Neural Engine

CoreML inference through WhisperKit, running on the hardware-accelerated Neural Engine of Apple Silicon rather than on a CPU thread or a datacentre GPU.

Nothing leaves the machine

No audio and no transcript is ever sent anywhere. Recordings exist only in memory for the duration of a transcription and are discarded immediately after.

Types where your cursor is

Inserts text at the caret through the macOS Accessibility APIs — Safari, Slack, VS Code, Mail, Obsidian, Terminal and anything else with a text field.

Cleanup you can tune

Deterministic rules drop filler words, resolve self-corrections and fix punctuation in milliseconds. Turn each rule off individually, or hand the text to a local model for a fuller polish.

Your choice of hotkey

Push-to-talk on fn, right ⌥ or the dictation key, or a toggle on fn + Space. Double-press for hands-free, esc to throw a dictation away.

No subscription

MIT licensed and free. There is no account, no trial, no seat count and nothing to cancel — because there is no server to pay for.

Getting started

Running in about a minute

The app is signed but not notarised, so macOS asks once before the first launch. Here is the whole path.

1

Install

Download the DMG and drag LocalFlow.app into your Applications folder.

2

Open it once

Right-click the app and choose Open, then confirm. macOS remembers the decision from then on.

3

Grant two permissions

Microphone, to hear you, and Accessibility, to type for you. The setup guide walks you through both and continues by itself once you grant them.

4

Hold and talk

Press fn anywhere in macOS, say your sentence, release. The text lands at your cursor.

Prefer to build it yourself? git clone the repo and run ./scripts/build_app.sh — Swift 6 toolchain, macOS 14 SDK, no other setup.

FAQ

Questions worth asking

Does any audio really never leave my Mac?

Yes. There is no networking code in the transcription path at all. The only time LocalFlow talks to the internet is when you explicitly download a speech model, and that is a one-off fetch from Hugging Face. You can verify this in the source, or just pull the network cable and keep dictating.

Which languages does it handle?

Whisper's multilingual models, so most major languages. German and English are what the cleanup rules are tuned for. Auto-detect copes well with mixing the two mid-sentence; naming a language explicitly helps on very short phrases.

Why does macOS warn me on first launch?

The app is code-signed but not notarised through the Apple Developer Program. Right-click the app and choose Open once, and macOS stops asking. If you would rather not trust the build, the whole thing compiles from source with one script.

Does it work on Intel Macs?

It runs, using the whisper.cpp backend instead of the Neural Engine. Expect noticeably higher latency than the sub-second figures quoted here, which are measured on Apple Silicon.

Why does it need Accessibility access?

That is the only supported way for an app to type into another app's text field on macOS. LocalFlow uses it to insert your text at the cursor, and — if you leave the option on — to read the few characters before the cursor so it can match capitalisation. That context is never stored and never read from password fields.

How much disk and memory does it use?

The app itself is 2.4 MB. Speech models are 75 MB to 470 MB depending on which tier you pick, downloaded once. You can choose whether the model stays resident in RAM for the fastest first word or loads on demand to save memory.
