Spezifikationen

Nativ. Ressourcenschonend. Autark.

Entwickelt in Swift und SwiftUI für minimale CPU-Last und null Speicher-Leaks.

Apple Neural Engine

CoreML-Inferenz über WhisperKit direkt auf den hardwarebeschleunigten 16-Core Neural Processing Units der Apple Silicon Prozessoren.

Vollständige Datensouveränität

Keine Übertragung von Audiodaten oder Transkripten an externe Server. Die Sprachdaten verbleiben ausschließlich im flüchtigen Arbeitsspeicher.

Direkte Textinjektion

Schreibt über macOS Accessibility APIs direkt an die aktive Cursorposition in Safari, Slack, VS Code, Mail, Obsidian oder Terminal.

Regelbasierte Vorfilterung

Deterministische Parsing-Algorithmen entfernen Füllfloskeln, bereinigen Whisper-Artefakte und korrigieren Satzkonstruktionen in Millisekunden.

Kein Abonnement

Vollständig unter Open-Source-Lizenz (MIT). Keine wiederkehrenden monatlichen SaaS-Kosten für alltägliche Spracheingabe.

Flexible Tastenmodi

Push-to-Talk über Hold Fn (Globus-Taste), rechte Option-Taste oder Control + Option. Automatische Umschaltung auf Freisprechmodus bei kurzem Antippen.
